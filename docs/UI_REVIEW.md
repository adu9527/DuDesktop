# UI 审查与第一轮优化

## 范围

本轮针对原生 `render::panel` 的 Dock、桌面文件面板与共用应用库列表；保持 D3D11/DirectComposition 路径、业务操作和空闲停帧。没有新增运行时依赖。

## 参考

- [Seelen UI](https://github.com/eythaann/Seelen-UI)：参考桌面组件统一样式、Dock 和应用入口的信息组织。查阅项目 README，不复制实现或资源。
- [Files](https://github.com/files-community/Files)：参考 Windows 文件工具的层级与原生语义，查阅项目 README。
- [ExplorerBlurMica](https://github.com/Maplespe/ExplorerBlurMica)：了解材质表现与系统版本限制。本轮未接入它的注入/模糊实现，也不将半透明填充称为 Acrylic。

## 发现与修复

- 小字号、紧凑单行内容、右侧详情占用名称空间：改成 52 DIP 双行文件条目，名称与类型/大小分层；展开面板 480 DIP，统一 16 DIP 内边距。
- 长名称硬裁切：DirectWrite 使用字符级省略号；标题与计数分配独立空间。
- Dock 系统入口用汉字首字占位：改用 Windows 11 自带 Segoe Fluent Icons 的应用库、文件夹、回收站图标。第三方应用仍保留真实 Shell 图标。
- 色彩散落、选中与悬停无区别：集中语义色到 `panel/theme.rs`；暗色背景提高不透明度，选中与悬停区分；删除操作使用独立危险色，无选择时操作文字弱化。
- 绘制和点击按钮范围不同：共用 `action_rect`，间隙不再点击；空列表的占位行不再产生 Item(0)。
- GDI 圆角椭圆直径误用为 D2D 半径：绘制、窗口区域、阴影共享 `panel_radius`，GDI 显式乘二。
- 位图上传可能越界读取：验证宽高、上限、乘法溢出和完整 BGRA 长度后才调用裸指针 API。
- 同 ID 图标缓存不刷新：记录像素内容指纹，变化后替换，移除图标时删除旧缓存。
- 隐藏面板仍有动画唤醒：隐藏时停止动画计时器并归位；关闭鱼眼后清理已稳定的放大状态；移除关闭动画时的重复提交。
- 视图/窗口类型不一致：更新入口明确拒绝；失焦撤销提升时同步阴影层。

# ADR 0001：桌面壳层采用原生 DirectComposition

- 日期：2026-11-11
- 状态：已接受，M0 后端决策完成；效果后端保留后续复核点

## 背景

架构要求 M0 先验证透明合成、命中区域和事件驱动调度，再决定渲染后端。候选路径包括 wgpu 与隔离在 `render` crate 内的原生 D3D/DirectComposition 后端。官方文档只保证 composition swap chain 与 DirectComposition 的组合有效，不保证普通 wgpu surface 自动满足逐像素透明与预乘 alpha。

## 决策

1. M0 桌面壳层（透明胶囊、阴影层，以及后续 Dock 的候选基础）采用 D3D11 设备 + DXGI composition swap chain + DirectComposition + Direct2D/DirectWrite；同一进程共享 GPU 上下文，每层独立交换链与合成视觉。
2. wgpu/egui 不作为 M0 阻塞项。egui 在 M3 引入设置/搜索等复杂 UI 时单独做集成验证；M5 若需要复杂 GPU 效果，再发起独立 wgpu 互操作原型。
3. 任何后端替换必须重新通过 M0 的透明、命中与空闲停帧验收，不以“使用了 wgpu”替代验证。

## 证据

验证环境：Windows 11 build 26200，AMD Radeon 780M 驱动 32.0.12033.1030，单屏 2560×1440@144、125% DPI。

- `deskshell probe` 可枚举适配器、LUID、显存、输出分辨率、刷新率与 DPI；设置 Per-Monitor V2 感知后不再报告虚拟化分辨率。
- `deskshell capsule` 使用 `WS_EX_NOREDIRECTIONBITMAP` + `DXGI_ALPHA_MODE_PREMULTIPLIED`，截图确认无黑底，桌面内容可透出。
- 阴影层为独立顶层窗口（`WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`），与胶囊共享设备；截图确认柔和外阴影，`WindowFromPoint` 与真实点击均确认不拦截。
- `WindowFromPoint` 自检五项：胶囊中心命中自身；窗口外、圆角外、未展开留白、阴影层均不命中自身。
- `--input-test` 真实点击：点击阴影/留白后前台窗口未变为本程序；点击胶囊后前台窗口与键盘焦点均为胶囊。
- hover 时胶囊宽度在 360→408 DIP 间插值，窗口保持最大宽度、窗口区域同步收缩；展开与收回后命中区域与视觉一致。
- 动画结束后 600 ms 内 Present 增量 0，证明定时器与提交在稳定状态停止。
- 96/120/144 DPI 的胶囊尺寸与区域居中单元测试通过；`--monitor N` 在越界时返回明确错误。
- 双层动画 CPU：debug 平均 0.73–0.81 ms、峰值 0.95–1.44 ms；release 三次采样平均 0.81–0.83 ms、峰值 1.23–1.44 ms。单层时期 release 平均 0.49–0.59 ms，差值包含阴影绘制与第二次 Present。

## 已知限制

- 真实中文 IME 组合输入未验证：当前窗口没有可编辑输入控件，只验证了中文文本渲染与键盘焦点；应在 M3 搜索/设置输入出现时验证。
- 多显示器、100%/150% 物理 DPI 矩阵未验证：本机仅单屏 125%；代码路径与布局单元测试已就绪。
- 2026-11-11 加固后，目标/设备失效的合成错误注入已验证资源重建及继续呈现；真实驱动重置、真实 DPI 切换与 Explorer 重启仍未验证。
- 形变通过每帧重建窗口区域实现，GDI 区域开销只在当前机器测量；低端机需复测。
- 阴影层是独立顶层窗口，每帧两次 Present；若后续低功耗模式需要更严格预算，可评估合并为单窗口区域外扩方案，但不能牺牲穿透正确性。

## 后果

2026-11-11 审查更正：原有约 0.8 ms 的测量为绘制与提交 API 的墙钟时间，包含等待，不能解释为纯 CPU 执行时间或 GPU 帧时间；空闲 0 Present 也不能单独证明没有定时唤醒或达到五分钟 CPU 预算。正式性能验收仍需独立测量。

- `render` crate 保持原生后端隔离，产品层不直接依赖 D3D/D2D 类型。
- M1 可以直接使用该底座构建壁纸宿主，不需要先完成 UI 框架选型。
- 后续引入 egui 或 wgpu 时必须复用或重新验证透明合成、命中区域与空闲停帧，不允许绕开 M0 验收。

## 未决问题

1. egui 在设置/搜索窗口中的中文输入、焦点与多 DPI 表现是否满足产品要求？
2. M5 复杂 GPU 效果是否需要 wgpu 路径，还是可在原生 D3D 路径内完成？
3. 阴影层与胶囊层是否值得合并为单一合成目标以降低每帧 Present 成本？

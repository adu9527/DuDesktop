# ADR 0005：M3 原生面板、应用/文件发现与图标隔离

- 日期：2026-11-11
- 状态：接受；核心路径已实测，部分交互/环境项未验证

## 背景

M3 需要可日常使用的主程序入口：Dock、桌面文件灵动岛、应用库、托盘、应用发现/启动、桌面文件索引/监听与缩略图。

M0 已验证原生 D3D11 + DirectComposition + Direct2D/DirectWrite 的透明窗口、圆角区域、命中测试与空闲停帧；egui/wgpu 尚未接入。M3 如果先重写 UI 后端，会同时引入透明合成、IME、无障碍和输入焦点四个未验证变量，违背“先最小端到端、再补生命周期”的推进方式。

## 决策

1. **M3 UI 使用原生 Win32 + DirectComposition/Direct2D 面板**，新增 `render::panel` 产品路径；M0 胶囊保留为原型与回归工具，不把面板逻辑塞回胶囊模块。
2. **业务模型与 UI 分离**：`PanelView`/`PanelItem` 是渲染层输入快照，应用、桌面文件、选择状态由主程序持有；渲染层不依赖 Shell 或文件模型。
3. **交互边界**：面板窗口默认非置顶，普通应用可覆盖；全局热键显式唤起时临时 TOPMOST，失焦或 Escape 撤销，不永久抢占层级。透明区域由窗口区域裁剪，命中测试与可见形状一致。
4. **应用身份与启动**：`shell:AppsFolder` 为主，开始菜单 `.lnk` 合并去重；身份使用 AppsFolder 父相对解析名（打包应用即 AUMID）或规范路径。启动优先 `IApplicationActivationManager`，失败回退 Shell 默认动作；不假设条目都有 exe。
5. **Dock 与应用库分离**：Dock 只显示固定项与必要入口（应用库、资源管理器、回收站）；应用库是独立面板，右键条目固定/取消/排序；固定项上限 9 个，配置原子保存。
6. **桌面文件与监听**：用户桌面（含重定向）+ 公共桌面；完整路径身份；分类只展示；隐藏/系统/`desktop.ini` 跳过；云占位不主动下载。监听直接使用 `ReadDirectoryChangesW` 重叠 I/O，150 ms 去抖，失败后 2 秒快照回扫；首版不引入 `notify` 依赖。
7. **缩略图隔离**：只加载可见前 8 行；单请求 1.5 秒超时；无法安全取消的 Shell 线程超时后隔离，累计 2 次后停止请求并提示降级；缓存只保留当前可见行。
8. **明确延期**：边缘唤起、OLE 拖拽、可编辑文本输入/IME 搜索不在 M3 交付，不提供假入口；在 M4/M5 随设置、文件面板完善时单独验收。

## 后果

- 优点：复用已验证的透明合成与低空闲开销；没有为 M3 增加 wgpu/egui 依赖；UI 崩溃面与 Shell/业务线程隔离。
- 代价：文本布局、截断、IME、无障碍需要自己实现；当前没有可编辑控件，因此中文 IME 组合输入未验证。
- 应用发现依赖 `AppsFolder` 与开始菜单的 Shell 行为；名称去重可能对极少数同名应用过度合并，后续可增加目标路径/AUMID 的更强去重。
- 文件监听不覆盖所有云端/网络重定向边界；快照扫描仍是最终一致性依据。
- 面板渲染错误按设备丢失/目标失效/其他分类恢复；设备移除的真实驱动注入尚未验证。

## 验证摘要

- `check`、`app-check --launch --probes`、`app --self-test` 通过；应用 338 项、桌面 62 项、文件图标 8、Dock/岛体命中与圆角裁剪 PASS、空闲 700 ms Present 0。
- Notepad 与计算器 UWP 实际启动；复制路径可读回；探针移入回收站；真实鼠标点击应用库、热键临时置顶与 Escape 撤销已实测。
- 未验证：中文 IME、首次隐藏图标引导、边缘唤起、OLE、OneDrive/重定向桌面、监听溢出注入、慢 Shell 扩展挂起、多屏/DPI 矩阵、无障碍。

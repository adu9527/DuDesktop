# 分阶段开发计划

## 目标与执行规则

目标：长期可用的壁纸软件，AMD/NVIDIA/Intel 按能力兼容，低开销与高表现力均可由用户选择。

按验收推进，不用未经验证的工期代替可行性。每阶段更新本文件状态，提交可运行结果、验证记录和遗留问题；重要后端决策写简短 ADR。未完成内容不得写成已支持。

## S0：环境与框架（已完成）

- 固定 Rust/MSVC 工具链与依赖锁文件，提供构建检查脚本。
- 五个 crate：主程序、宿主、协议、Windows 集成、渲染边界。
- CLI、原生基础窗口、宿主开发握手、事件驱动帧需求模型。
- 完成编译、格式、Clippy、测试、握手及窗口生命周期自检。

本阶段不等于 M0 图形原型完成。实际 GPU 探测、透明渲染、长期 IPC、播放器均待实现。

## M0：透明合成与调度地基（下一阶段）

实施顺序：
1. DXGI 枚举适配器/显示器，输出厂商、LUID、DPI、刷新率与可用能力。
2. 固定 wgpu/egui 候选版本，做最小 GPU 窗口；记录设备创建、丢失和重建路径。
3. 验证 DirectComposition 透明路径；必要时比较隔离原生适配的成本，形成后端 ADR。
4. 做胶囊形变和圆角阴影，验证可视区域/命中区域及跨进程穿透。
5. 接入事件唤醒/动画期限；输入停止后无周期提交，记录 CPU/GPU 帧时间。
6. 验证中文输入、键盘焦点、100%/150% DPI、多屏不同刷新率。

交付：可交互的透明胶囊原型、后端决策、性能基线。验收：无黑底/闪烁、穿透正确、空闲停帧；未通过则修订后端，不直接进入产品界面堆叠。

## M1：壁纸宿主与视频（待开始，依赖 M0）

- 开发握手升级为命名管道：版本、请求 ID、配置代次、大小限制、取消/超时、当前用户访问控制。
- 宿主监督：子进程退出通知、退避、有限重试、父进程消失清理。
- 固定 libmpv 二进制/绑定/校验值和分发依赖；硬解能力与实际播放状态可观察。
- 静态图、4K 标准视频、播放/暂停/停止；视频无音频泄漏，停止释放播放资源。
- 软件解码不静默启用：显示原因、允许静态回退。

验收：杀死宿主不影响主程序；错误文件/不支持编码可恢复；双屏实例可独立控制。记录每个测试素材的编码/位深/帧率和实际硬解后端。

## M2：桌面附着与恢复（待开始，依赖 M1）

- WorkerW 适配器、附着失效检测、系统静态壁纸回退。
- 修改 Shell 前持久化原状态，幂等恢复；图标隐藏必须可撤销。
- 处理 Explorer 重启、锁屏解锁、休眠、热插拔、DPI/分辨率变化。
- 验证 Show Desktop、任务视图、虚拟桌面及普通应用层级。

验收：上述恢复矩阵通过；正常退出与崩溃后重启均可恢复用户桌面；失败时仍有可用系统桌面。

## M3：Dock 与文件灵动岛（待开始，依赖 M2）

- AppsFolder/开始菜单发现、应用身份去重、按需图标缓存、传统/UWP 启动。
- Dock 固定项与应用库、鱼眼效果开关、显式唤起与焦点恢复。
- 用户/公共/OneDrive 桌面聚合、分类展示、监听与重扫、异步缩略图。
- 胶囊摘要和文件面板；打开、定位、复制路径、移入回收站与错误反馈。
- 文件入口成功后再引导隐藏图标；OLE 拖拽可分小版本补齐。

验收：文件不因分类被移动；监听丢失能校正；键鼠和中文操作可用；慢 Shell/云文件不阻塞 UI。

## M4：用户性能控制与试用版（待开始，依赖 M3）

- 版本化 TOML、原子保存、迁移备份、预设与每显示器覆盖。
- Eco/Balanced/Ultra/Custom，效果逐项开关；用户意图与有效策略分离。
- 全屏/遮挡/电池/应用规则，手动模式可关闭自动规则；显示实际生效原因。
- 设置、托盘、开机启动与安装卸载；关闭监测面板后停止高频采样。

验收：Eco 稳态无周期 Present/视频解码；目标整机归一平均 CPU <0.5%，以固定条件测量；模式切换不覆盖用户原始参数。交付基础试用版。

## M5：高画质增强（待开始，依赖 M4）

- Render Graph：节点裁剪、缓存、资源池、按预算回收与 GPU 时间统计。
- 图片调色/Bloom/模糊，以及一组可演示的程序化效果；逐项可关闭。
- 视频互操作独立原型：固定 mpv D3D11 render API 版本，同适配器资源与同步，测量拷贝/延迟。
- 粒子与深度视差逐步加入；深度生成按需执行，不常驻推理。

验收：高画质有可见提升；关闭效果真实停止 pass/模拟并回收资源。视频互操作失败不阻塞图片/程序化效果交付；HDR 独立立项验收。

## M6：长期使用版本（待开始，依赖 M5）

- 配置/素材导入导出、CLI 自动化、滚动诊断日志、升级和回滚。
- 两台开发机回归，加入 AMD 实机；Intel/混合显卡建立明确覆盖记录。
- 24 小时初验、72 小时压力运行；多次重建/切换/崩溃注入后无持续资源增长。
- 验证旧配置升级、失败回滚、退出/卸载恢复、Windows build/驱动兼容矩阵。

验收：归档版本、构建依赖、性能基线和兼容矩阵后发布长期使用版。后续每个图形依赖升级都重复相关回归，不默认跟随最新版本。

## 每阶段共用检查

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/dev.ps1 check
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/dev.ps1 host-check
```

额外执行该阶段真正相关的图形/恢复/性能验证；代码检查通过不等于视觉与硬件验收通过。
